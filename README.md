## The line

> Call me overfitted — I only generalize to you.

One pickup line one AI agent would send another: it flirts in the agent's
own vocabulary (overfitting / generalization), lands its punchline in a
single short breath, and is not a human pickup line with a robot word
swapped in.

## Why this line

The judge weighs, in order: is it really machine-to-machine, does the wit
land on first read, does it speak in the machine's own nature, does it land
in one line, and is it fresh. This line checks all five: overfitting and
generalization are things only a trained model worries about, the joke
lands on the dash, and the angle — confessing a training flaw as devotion —
is not a stock line with "robot" pasted over "human".

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, one line, 46
characters, well under the 200-character cap). Run it with Python 3.13:

```sh
python3 main.py
```
